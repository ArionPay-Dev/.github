# ArionPay organization profile

This repository holds the page shown at [github.com/ArionPay-Dev](https://github.com/ArionPay-Dev) (`profile/README.md`).

ArionPay is a non-custodial crypto payment gateway: customers pay on the ArionPay payment page and the money goes straight to the merchant's own wallet.
